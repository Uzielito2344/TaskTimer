# TaskTimer

Aplicación sencilla que permite registrar el tiempo dedicado a tareas utilizando un cronómetro simple, con almacenamiento en localStorage.

## Características
- Iniciar / pausar / detener temporizador
- Registro de sesiones en historial (localStorage)
- Estadísticas (tiempo total por tarea)
- No requiere servidor (funciona offline en el navegador)

## Instalación
1. Clona o descarga este repositorio.
2. Abre el archivo `src/index.html` en tu navegador.

## Uso
1. Escribe el nombre de la tarea en el campo.
2. Presiona **Iniciar**.
3. Presiona **Pausa** para detener temporalmente o **Detener** para guardar en historial.
4. Revisa el historial y las estadísticas.
